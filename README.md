## کتابخانهٔ طراحی، نه ویترین نمونه‌های مصنوعی

تمام مدل‌های منحصربه‌فرد منابع معرفی‌شده را در دو بخش جدا می‌بینید:

**طرح‌های آماده + پرامپت:** دستورهای شات‌کرافت، ۱۵ سبک مستقل `mg-styles-15`، الگوهای `video-talkcraft` و `anything2explainer`. مدل‌های چندگانهٔ هر طرح در پنل مدل‌ها قابل‌انتخاب‌اند. متن و دستور فارسی در کنار لینکِ دستور اصلی قابل کپی است.

**کامپوننت‌ها:** الگوهای حرکت پیوستهٔ `onetake`، فونت‌های آزاد فارسی، چهار مدل قلم خود پروژه، و کتابخانهٔ صوتی اصلی **۵ قطعه موسیقی و ۱۴۹ افکت صوتی** شات‌کرافت که بر اساس منبع و مجوز واقعی دسته‌بندی شده‌اند.

کتابخانه امکان جست‌وجو، فیلتر **منبع خاص**، دسته، تگ و نام مدل را دارد. هیچ سقف مصنوعی دو مدل در هر دسته وجود ندارد. فقط مواردی با هویت منبع دقیقاً یکسان حذف می‌شوند.

### پیش‌نمایش‌ها و واقعیت فارسی‌سازی

طرح‌هایی که **خودِ فایل ویدیوی فارسی مستقل و تأییدشده** ندارند، تنها به‌عنوان **مرجع اصلی، هنوز فارسی نشده** معرفی می‌شوند؛ نشان‌دادن متن فارسی روی کارت یا ساخت یک پیش‌نمایشِ نامرتبط به معنی رندر فارسی منبع نیست. نسخهٔ اصلی برای بررسی دقیق حرکت و پرامپت در دسترس است. با انتخاب چند مورد می‌توانید مشخصات صحنه و دستور ساخت فارسی را به‌صورت JSON دریافت کنید و برای بازآفرینی واقعی تحویل دهید.

نمونه‌های مصنوعیِ تکراری و ترک‌های تولیدیِ قبلی از Library حذف شده‌اند. هستهٔ موتور قلم فارسی و چهار ابزار قلم حفظ شده است.

### صدای منابع و مجوزها

فهرست صدای اصلی، منبع موسیقی، نام اثر، هنرمند (درصورت وجود) و لینک نمونهٔ اصلی را نشان می‌دهد. **چهار موسیقی و ۱۴۴ افکت** دارای URL ثبت‌شده‌اند. یک موسیقی و پنج افکت که منبع دقیق ندارند تا تأیید حقوق استفاده غیرقابل‌پخش‌اند.

فایل‌های Mixkit بر اساس شرایط خاص خود در پروژه‌های نهایی قابل استفاده‌اند، اما بازنشر فایل خام به‌عنوان فایل پک صوتی یا استخراج و انتشار جداگانهٔ موسیقی از ویدیوی نمایشی، بدون مجوز مناسب انجام نمی‌شود. برای جزئیات، [مشخصات منابع](https://github.com/Vincentwei1021/video-shotcraft/blob/main/assets/audio/ATTRIBUTION.md) و [مجوزهای Mixkit](https://mixkit.co/license/) را ببینید.

## نحوهٔ اجرا

```bash
python3 -m http.server 8080
# http://localhost:8080/library/
```

برای توسعهٔ موتور خطاطی:

```bash
cd skills/anidoodle/engine
npm ci
node tools/persian-qa.mjs
```
